# Solid Edge Learning Resources – Basic to Intermediate

For your engineering innovation portfolio, I recommend learning Solid Edge in a structured sequence: 2D Sketching → 3D Part Modelling → Mechanical Features → Assembly Design → Sheet Metal → Engineering Drawings.

The objective is to become capable of designing components for your agricultural robots, drones, Raspberry Pi systems, sensor enclosures and robotic mechanisms.

5. Simulation, FEA and design validation.
